    Application Interaction Chart
    =============================

    ┌──────────────────────────────────────────────┐
    │ 1. controlleradvice                          │
    │ ProductServiceExceptionHandling.java         │
    │ Handles exceptions raised during a request.  │
    └──────────────────────┬───────────────────────┘
                   │ exception response
                   v
    ┌──────────────────────────────────────────────┐
    │ 2. controller                                │
    │ ProductController.java                       │
    │ SampleController.java                         │
    │ Receives HTTP requests and returns responses. │
    └──────────────────────┬───────────────────────┘
                   │ calls
                   v
    ┌──────────────────────────────────────────────┐
    │ 3. service                                   │
    │ ProductService.java                           │
    │ FakeStoreProductService.java                  │
    │ Contains application and business logic.      │
    └──────────────────────┬───────────────────────┘
                   │ converts external data
                   v
    ┌──────────────────────────────────────────────┐
    │ 4. dto                                       │
    │ FakeStoreProductDto.java                     │
    │ Represents data received from Fake Store API. │
    └──────────────────────┬───────────────────────┘
                   │ maps data into
                   v
    ┌──────────────────────────────────────────────┐
    │ 5. models                                    │
    │ Product.java, Category.java, BaseModel.java  │
    │ Represents the application's domain objects. │
    └──────────────────────────────────────────────┘

    Normal request flow:
    controller -> service -> dto -> models -> controller response

    Exception flow:
    controller/service -> controlleradvice -> error response
